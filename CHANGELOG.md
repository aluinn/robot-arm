# Changelog

All notable changes to this project are documented here. The format follows
[Keep a Changelog](https://keepachangelog.com/en/1.1.0/) and the project uses
[Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [Unreleased]

### Added
- Open-source project scaffolding: contributing guide, code of conduct, security policy, roadmap, issue and PR templates, Dependabot config.
- `docs/` with architecture notes, usage reference, performance measurements and issue drafts.
- Dev tooling: dependency-free dev server, ESLint, TypeScript `checkJs`, unit tests, a Playwright smoke test, CI and CodeQL workflows, and a GitHub Pages workflow.
- README screenshots generated by `npm run screenshots`.

### Changed
- README restructured; the full controls and feature reference moved to `docs/USAGE.md`.

## [0.1.0] - 2026-11-05

Initial version, as developed before the project was prepared for open-source release.

### Added
- Five-joint arm with parallel gripper, closed-form inverse kinematics and critically damped joint motion.
- cannon-es rigid-body physics at a fixed 120 Hz step, with a locked-grasp model.
- Tower and Pyramid challenges with ghost targets, timer and stored best times.
- Record and Autopilot with deterministic replay, timeline scrubbing, speed control and JSON export/import.
- Auto-Build for Tower, Pyramid, Wall and Staircase from any block layout.
- Camera presets, synthesized sound, clean mode and a phone layout.
